# Tu Tien Du Hanh

Game nhap vai 2D chay tren trinh duyet. Vertical slice co may chu tham quyen.

Prototype HTML/JS cu nam trong `legacy/`.

## Chay local

```bash
cd apps/server/src/TuTien.Api
dotnet run --urls http://localhost:5080
```

```bash
cd apps/web
npm install
npm run dev
```

- Web: http://localhost:5173
- API: http://localhost:5080
- Swagger: http://localhost:5080/swagger
- Health: http://localhost:5080/health
